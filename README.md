# Honey Pasika — Робочий MVP

Сайт власної пасіки з повноцінним інтернет-магазином, бекендом на Node.js / Express та базою даних SQLite.

## Технічний стек

- **Frontend**: React 19, Vite 8, Tailwind CSS, React Router 7
- **Backend**: Node.js (Express 5, better-sqlite3, multer, cookie-parser)
- **База даних**: SQLite (`pasika.db` у режимі WAL з атомарними транзакціями)
- **Вимоги до Node.js**: Node >= 20.19.0 (зафіксовано в `package.json` та `.nvmrc`)

## Швидкий старт

1. Скопіюйте файл змінних оточення:
   ```bash
   cp .env.example .env
   ```
2. Встановіть залежності:
   ```bash
   npm install
   ```
3. Запустіть проєкт у режимі розробки (одночасний старт бекенду на порту 3001 і клієнта на 5173):
   ```bash
   npm run dev
   ```
   Відкрийте [http://localhost:5173](http://localhost:5173) у браузері.

### Продакшн запуск

```bash
npm run build
npm start
```
Сервер запуститься на `http://localhost:3001` та роздаватиме як API, так і статичні файли фронтенду.

## Адмін-панель

- **URL**: `/admin`
- **Логін за замовчуванням**: `admin`
- **Пароль за замовчуванням**: `pasika2026` (налаштовується у файлі `.env` через `ADMIN_PASSWORD`)
- **Безпека**: Авторизація реалізована на сервері з хешуванням паролів (scrypt) та сесійними cookie з прапорцем `httpOnly`. Жодні паролі та сесії не зберігаються в клієнтському коді чи localStorage.

## Інтеграції та можливості MVP

- **База даних та замовлення**:
  - Товари, категорії, замовлення, налаштування та сесії зберігаються в SQLite.
  - Серверне створення замовлення: генерація унікального номера, нормалізація та валідація номерів телефонів України (`+380...`), перевірка email.
  - Захист від повторного сабміту (idempotency key та захист від спаму).
  - Атомарна перевірка та списання залишків на складі в єдиній транзакції (з поверненням залишків у разі скасування замовлення).
- **Сховище чеків**:
  - Чеки завантажуються на сервер через `multipart/form-data` у каталог `storage/receipts/`.
  - Зберігаються реальні посилання на файли, доступні для перегляду та завантаження в адмінці.
- **Доставка (Нова пошта та Укрпошта)**:
  - Серверні ендпоінти пошуку міст та відділень (`/api/delivery/cities`, `/api/delivery/branches`).
  - Підтримка реальних API Нової пошти (`NOVA_POSHTA_API_KEY`) та Укрпошти (`UKRPOSHTA_API_KEY`) з прозорим demo fallback.
  - Збереження реальних Ref/ID міста й відділення в замовленні.
- **Telegram сповіщення**:
  - Відправка повідомлень через Telegram Bot API безпосередньо з сервера.
  - Токен бота та chat ID зберігаються виключно у серверному `.env` (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) і ніколи не потрапляють на клієнт.
  - Всі сповіщення логуються в базу даних та доступні на Дашборді адмінки.
