# Папка для медіа-файлів TikTok (@honey.dsv)

Ця директорія призначена для розміщення локальних відео-прев'ю або постерів з офіційного TikTok-профілю власниці пасіки:
**https://www.tiktok.com/@honey.dsv**

## Відповідність файлів та реальних відео:

1. **Відео 1**
   - Файл відео: `public/tiktok/video-1.mp4`
   - Постер: `public/tiktok/preview-1.jpg`
   - Посилання: https://vt.tiktok.com/ZSbLujdn8/

2. **Відео 2**
   - Файл відео: `public/tiktok/video-2.mp4`
   - Постер: `public/tiktok/preview-2.jpg`
   - Посилання: https://vt.tiktok.com/ZSbLujG9o/

3. **Відео 3**
   - Файл відео: `public/tiktok/video-3.mp4`
   - Постер: `public/tiktok/preview-3.jpg`
   - Посилання: https://vt.tiktok.com/ZSbLuJ8S1/

4. **Відео 4**
   - Файл відео: `public/tiktok/video-4.mp4`
   - Постер: `public/tiktok/preview-4.jpg`
   - Посилання: https://vt.tiktok.com/ZSbLuM7kb/

## Поведінка системи:
- При наведенні курсору на десктопі система автоматично запускає локальне відео (`video-X.mp4`) без звуку (muted, loop, autoplay).
- Коли курсор залишає картку, відео негайно зупиняється та повертається постер (`preview-X.jpg`).
- Якщо локальний файл `.mp4` ще не завантажено, картка стабільно відображає якісний постер без збоїв чи помилок.
- При кліку на картку відкривається саме відповідне оригінальне TikTok-відео.
